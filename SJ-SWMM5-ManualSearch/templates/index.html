Welcome to SWMM5 Manual Search

A searchable companion for the EPA SWMM 5.2 Reference Manual

Scott Jeffers, PE, PhD converted the entire EPA Storm Water Management Model (SWMM) 5.2 User's Manual from its original PDF format into a structured, web-based collection hosted at swmm-manual.netlify.app.

This search engine crawls that collection and builds a full-text index so you can instantly find any topic, parameter, or method across all 53 chapters and 631 sections of the manual — no more scrolling through 800+ pages of PDF documentation.

INP File Cross-Reference: Search any keyword like "conduits" or "infiltration" and see the manual explanation alongside the actual INP file syntax, field definitions, and example entries — side by side.
